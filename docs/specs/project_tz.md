Имеется дизайн макет блога маркетплейса, доступный по ссылке
[https://www.figma.com/design/0iOMBzhZVXTebSCdh5ZkAG/Маркетплейс-(Copy)?node-id=0-1\&p=f\&t=hdkkJcXhqylwjRsR-0](https://www.figma.com/design/0iOMBzhZVXTebSCdh5ZkAG/Маркетплейс-\(Copy\)?node-id=0-1&p=f&t=hdkkJcXhqylwjRsR-0)

Нужно разработать по нему API для того, чтобы Frontend разработчик смог реализовать все возможности блога, отображенные на макетах.

В проекте должна быть реализованы:

1. Форма аутентификации и регистрации

Когда пользователь регистрируется ему должно отсылаться электронное письмо на указанный почтовый адрес о успешной регистрации. Письмо должно отсылаться через брокер сообщений и воркер, чтобы не тормозить систему тяжелым запросом.
Когда пользователь вводит правильные логин и пароль, то ему должен выписываться JWT токен, который будет сохраняться в cookie. В дальнейшем Backend должен проверять наличие токена с помощью middleware при каждом запросе к системе.

2. Эндпоинты на получение статей блога

Должны быть эндпоинты:

* Список статей
* Создание категории
* Список категорий
* Добавление новой статьи
* Изменение статьи
* Удаление статьи

Эндпоинт списка статей должен быть с постраничной пагинацией. Должно быть ограничение на максимальное количество элементов на одной странице. Также этот эндпоинт должен иметь query параметры:

*  “search” по которому будет происходить полнотекстовый поиск по списку статей. Полнотекстовый поиск нужно делать на движке postgresql.
* “category\_id” для фильтрации по конкретной категории
* “page\_number” для пагинации
* “page\_size” для пагинации

При создании статьи нужно указывать ее текст, название, категорию, изображение. После создания должны автоматически проставляться дата создания и дата изменения. Изображения рекомендуется хранить в S3 хранилище, например Minio.

Эндпоинт удаления статьи должен осуществлять фейковое удаление. Это значит, что для пользователя статья удаляется, но фактически остается в БД. Рекомендуется сделать такую реализацию, чтобы удаленные статьи лежали в отдельной таблице и удалялись из основной.
